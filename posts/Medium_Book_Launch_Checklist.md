# The Shattered Crown Launch Checklist (What Actually Worked)

Got my dark fantasy novel $2,400 first week without spending on ads. This is the exact 15-step checklist I used.

## Pre-Launch (Months 1-2)

**Week 1-2: Category Research**
- Browse Amazon's "Fantasy > Dark Fantasy" category
- Find books with 300+ reviews + 4.5+ stars
- Note pricing ($4.99-$6.99 works)
- Copy 5 book descriptions and analyze structure

**Week 3-4: Cover Design**
- Used Canva Pro + fantasy template
- Key rule: Main character face clearly visible (readers buy characters)
- Color psychology: Red = danger, dark = serious
- Test on phone screen (thumb-sized thumbnail must work)

**Month 2: Content Preparation**
- Write 10+ book description variations (test different hooks)
- Create 3 reader testimonials from beta readers
- Design 5 social media graphics (quote cards, character art)

## Launch Week

**Day 1-2: Price Promotion**
- Launch price: $0.99 for 48 hours
- Run Amazon Ads: $5/day, target "dark fantasy" + "vampire" keywords
- Email list from previous books (if available)

**Day 3-4: Review Campaign**
- Contact 50 Goodreads giveaway followers
- Message 20 book bloggers for early review copies
- Personal messages to 10 YouTube viewers who asked about next book

**Day 5-7: Amplification**
- Reddit: r/Fantasy and r/DarkFantasy posts (AMA format works)
- Facebook groups: "Indie Authors" + "Fantasy Book Lovers"
- Instagram: Cover reveal + behind-the-scenes video

## Post-Launch Optimization

**Metrics to Track Daily:**
- Amazon ranking in "Dark Fantasy" (target Top 100)
- Page views (Amazon KDP reports)
- "Also Bought" clicks (indicates proper categorization)
- Review velocity (aim for 1 review per 50 sales)

**Adjustments I Made:**
- Pricing: Changed from $4.99 to $3.99 (volume over margin)
- Keywords: Added "wraith" + "lich king" (lower competition)
- Description: Moved character introduction earlier (improved keyword density)

## The Numbers

- Week 1: $2,400 (price $0.99-$3.99)
- Week 2: $1,800 (price $3.99)
- Week 3: $1,200 (price $3.99)
- Total Month: $5,400

Cost: $0 ads (organic only)
